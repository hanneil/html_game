# 星际突击 · SPACE STRIKE

纯前端 3D 太空飞船射击游戏。驾驶飞船穿越小行星带，摧毁陨石与追击无人机，收集道具，冲击最高分。

基于 [Babylon.js](https://doc.babylonjs.com/) 开发，**零依赖、零构建**，本地内置引擎文件，断网也能玩。

## 快速开始

方式一：直接用浏览器打开

```
双击 index.html（或拖入 Chrome / Edge）
```

方式二：本地静态服务器（推荐）

```bash
# 任选其一
npx serve .
python -m http.server 8000
```

> 需要支持 WebGL 的现代浏览器（Chrome / Edge 最佳）。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| 鼠标 | 转向瞄准（点击画面锁定鼠标） |
| W / S | 上升 / 下降 |
| A / D | 向左 / 向右平移 |
| 空格 / 左键 | 射击 |
| Shift | 推进加速 |
| ESC | 返回主菜单（游戏中需按两次） |

飞船自动向前飞行，WASD 只负责躲闪。

## 游戏机制

- **波次升级**：得分越高，敌人刷新越快、速度越快
- **伤害系统**：
  - 小陨石 1 血 / 中陨石 2 血 / 大陨石 3 血
  - 无人机 2 血
  - 普通翼子弹伤害 1，中央重弹（紫色大弹）伤害 2
- **道具光球**（击毁敌人概率掉落，可飞过或打中拾取）：

  | 道具 | 效果 |
  | --- | --- |
  | 蓝球 · 多弹道 | 弹道 +1 层，最多叠 3 层（2 → 7 发/次），持续 12 秒 |
  | 绿球 · 修复 | 船体 +30（上限 100） |
  | 金球 · 积分加倍 | 得分 ×2，持续 10 秒 |

- **高度提示**：敌人身上的竖线上有亮色横杠，横杠位置 = 你所在高度；横杠钻进敌人体内且变红 = 同高度，碰撞危险
- **最高分**：本地 `localStorage` 持久保存

## 技术要点

- Babylon.js 场景：雾效、半球光/方向光、程序化星空球体
- 飞船由基础几何体拼装，probe 节点计算朝向基
- 陨石为顶点随机扰动的球体 + 法线重计算
- 爆炸使用粒子系统，音效由 WebAudio 实时合成（无音频文件）
- 全局错误捕获浮层，方便调试
